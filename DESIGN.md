# DESIGN: Notepad Hub 4

## Authority
- Approved source: исходные файлы токенов `ui/src/design-system.css` (корень `:root`) и `ui/src/layout-v4.css`. Это текущее состояние, а не макет.
- Approval reference: владелец принимал интерфейс по скриншотам в переписке по шагам; письменного выбора варианта по макетам нет (ворота G3 не пройдены).
- Fidelity target: деловой плоский стиль, светлая тема Fluent (Windows 11), тёмная тема на тех же токенах.
- Allowed deviations: только по решению владельца.

## Product character
- Audience: один владелец, ежедневная работа с текстом на русском.
- Brand attributes: спокойный, деловой, без украшений; один акцент (синий) и один выделенный акцент ИИ.
- Density: плотная верхняя строка, широкое поле текста по центру.

## Tokens
- Цвет (светлая тема): canvas `#f5f6f8`, surface `#ffffff`, surface-soft `#f8f9fb`, surface-hover `#f2f4f8`, line `#e7e9ee`, line-strong `#e1e4ea`, ink `#1f1f1f`, ink-soft `#626262`, ink-muted `#626a75`, accent `#0067c0`, accent-strong `#005a9e`, accent-soft `#eaf2fc`.
- Цвет (тёмная тема): класс `.theme-dark`, значения в `layout-v4.css`.
- Шрифт: один шрифт интерфейса `--font-ui` (Segoe UI Variable Text, Segoe UI, затем системный) для всех кнопок, вкладок и заголовков; шкала: строки списка 13,5, плитки разделов 13, счётчики и значки 12, названия групп 11,5, нижняя строка 12,5, название заметки в верхней строке 14, веса 500 и 600. Размеры 12, 14, 15, 18 px относятся к тексту редактора.
- Отступы: 4, 8, 12, 16, 24, 32 px. Тень `--shadow`.

## Components
- Верхняя строка: три зоны (место, заметка, инструменты), группа Правка (отменить, повторить), затем ИИ, поиск, «⋯». «Файлы и данные» живут в «Настройках приложения» (R17); кнопок «Назад/Вперёд» и сравнения нет (R23, R31). Подробно: `docs/design/2026-10-15-topbar.md`.
- Библиотека (сверху вниз): «Проекты» с кнопкой «+», «Заметки» выбранного проекта (без полосы прокрутки), свёрнутые метки, блок 2×2 «Избранное, Недавние, Архив, Корзина», «Настройки приложения». Над проектами строка «Все заметки». Свёрнутая библиотека (вручную или при открытии ИИ) это столбец значков 52 px: «Избранное», «Недавние», «Архив», «Корзина» со счётчиком. Кнопка сворачивания одна, внизу библиотеки справа от «Настроек», в столбце значков внизу столбца (R4).
- Корзина: список в основной области (название, «удалена N мин назад · осталось N дн.», «Восстановить», «×»), «Очистить корзину» внизу.
- Вкладки: плоские, с тонкими разделителями, активная с акцентной линией сверху, ширина от 130 px, при переполнении прокрутка; ★ у закреплённой заметки; новая заметка называется «Заметка N» (N по порядку среди заметок, которым имя дало приложение; R11, R29). Нижняя строка: «Сохранено», метки, «Изменено», строка и столбец, слова и знаки, кнопки «Фокус», «Сравнение», «Метки», масштаб (R15, R31).
- Панель ИИ: справа, ширина `--ai-w`, меняет ширину перетаскиванием.
- Окна: подтверждение (корзина, восстановление, очистка), форма, сравнение двух заметок.

## Screens and flows
1. Редактор заметки с библиотекой слева и вкладками сверху (основной экран).
2. Экран «Нет открытых заметок» (кнопки «Новая заметка» и «Открыть файлы…»).
3. Две заметки рядом с полосой выбора сторон и сравнением.
4. Панель ИИ справа (запрос, преобразования, свои инструкции).
5. Корзина и архив как разделы библиотеки; очистка корзины.
6. Диалоги: подтверждение, переименование, метки, история версий, свойства, резервная копия.
