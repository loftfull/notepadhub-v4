## Общие правила
1. Одно действие в одном месте. Перед добавлением кнопки найти все такие же действия (`grep` по подписям) и убрать дубли.
2. Функция ИИ живёт в панели ИИ. Верхняя строка содержит только действия над заметкой и видом.
3. Любое новое размещение элемента сверяется с таблицей выше. Если требования нет, место выбирается по тому, к какому слову из запроса относится функция («по содержимому или запросу» → ИИ), и решение записывается строкой в таблицу.
4. Критики и дизайнеры получают этот реестр вместе с задачей и проверяют изменение по нему.
