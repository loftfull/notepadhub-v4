# Паспорт проекта Notepad Hub 4

Дата: 2026-10-09. Статус: предварительная версия (preview), не заменяет установленную 3.0.5.

## Цель
Быстрый локальный блокнот для Windows с папками, вкладками заметок и AI-помощником. Данные остаются на компьютере пользователя.

## Что это за приложение
```
 WPF-окно (NotepadHub4.exe)
   ├─ WebView2: интерфейс BlockNote (React) из папки ui\
   ├─ Мост (контракт v1): JSON-сообщения страница ↔ хост
   ├─ Ядро NoteStore: файлы data-v3 (формат 3.0.5) + блоки notes-blocks
   └─ AiService: Ollama (локально) и OpenRouter (облако, по согласию)
```

## Хранение (решение, ADR 0002)
- Файлы заметок те же, что у 3.0.5: `notes-meta\<id>.json`, `notes-content\<id>.txt`, `history\`.
- Добавлено: `notes-blocks\<id>.json` (блоки редактора + хэш текста) и `settings-v4.json`.
- Если текст `.txt` изменился вне v4 (например, в 3.0.5), блоки считаются устаревшими и строятся заново из текста.
- Текстовое зеркало без потерь строк: текст → блоки → текст возвращает исходные строки (тесты `textFormat.test.mjs`).

## Решения по AI (Resource Registry + stack-advisor, 2026-10-09)
| Вопрос | Решение |
|---|---|
| Провайдер по умолчанию | Ollama на этом компьютере (данные не уходят). Адрес только loopback |
| Облако | OpenRouter: ключ пользователя, DPAPI-хранилище, явное согласие, подтверждение платного запроса |
| Не брать | router.cheap и подобные шлюзы на чужих подписках: личные данные заметок |
| Секреты в тексте | Автоматическая блокировка отправки в облако (ключи, токены, пароли, приватные ключи). Локально разрешено |
| Лимиты | вход ≤ 24 000 симв., выход ≤ 24 000 симв. и 512/1536 токенов; облако 10 запросов/мин и 100/день; тайм-аут 90 с; потолок цены $0,25 за запрос; один автоповтор только на временные сбои |
| Логи | Только провайдер, модель, операция, результат, время, request-id. Без текста заметок и ключей |
| Оценка стоимости | Локально $0. Облако при 200 запросах/мес ~ $0,06–0,20 для моделей класса flash; до ~$3,6 для топовых (оценка из реестра от 2026-10-08, цены не перепроверены) |

Не реализовано из рекомендаций: месячный бюджет (мягкий $2 / жёсткий $5) и счётчики токенов. Нужно добавить до релиза.

## Перед релизом (чек-лист AI-стандарта)
- [x] Простейший вариант: один вызов, без агентов.
- [x] Лимиты, условия остановки, подтверждения.
- [ ] Evals на 20–30 реальных заметках (русский текст, локальная и облачная модель).
- [x] Повторы только для временных сбоев; request-id логируется.
- [x] Внешние данные и вывод модели считаются недоверенными (текст в маркерах; результат показывается как предложение).
- [x] Нет секретов в промптах и логах (фильтр + тест).
- [ ] Зафиксировать версии моделей; месячный бюджет.

## Известные ограничения
- Все заметки загружаются в память при старте (для сотен заметок это нормально, для тысяч нужна ленивая загрузка).
- Резервные копии `.nhub` и восстановление, интерфейс истории версий — в плане.
- Установка рядом с 3.0.5 и ассоциация `.txt` — в плане.
