# ADR 0002. Формат хранения заметок

Статус: принято, 2026-10-09.

## Решение
Notepad Hub 4 использует папку данных Notepad Hub 3.0.x (`%LOCALAPPDATA%\NotepadHub\data-v3`) без изменения существующих файлов.

| Файл | Кто пишет | Содержимое |
|---|---|---|
| `projects.json` | 3.0.x и 4 | папки |
| `notes-meta\<id>.json` | 3.0.x и 4 | свойства заметки (PascalCase, те же поля) |
| `notes-content\<id>.txt` | 3.0.x и 4 | текст заметки |
| `history\<id>\*.txt` | 3.0.x и 4 | прежние версии |
| `notes-blocks\<id>.json` | только 4 | блоки редактора и SHA-256 текста, из которого они получены |
| `settings-v4.json` | только 4 | настройки окна и интерфейса (settings.json от 3.0.x не трогаем) |

## Правило согласованности
Текст `.txt` главный. Блоки действуют, пока SHA-256 текста равен записанному в `notes-blocks`. Если текст изменили вне v4 (например, в 3.0.5), блоки считаются устаревшими, и интерфейс строит их заново из текста. Так две версии не расходятся незаметно.

## Текст ↔ блоки без потерь
`textToBlocks` и `blocksToText` (ui\src\textFormat.ts) возвращают исходные строки для любого входа. Структурой становятся только однозначные префиксы (`# `, `- `, `- [ ] `, `1. ` по порядку, `> `, ограждённый код). Всё остальное остаётся абзацем. Строки вида `# комментарий` в `.env` или команды shell не искажаются.

## Откат
Удалить `notes-blocks` и `settings-v4.json` можно в любой момент: заметки не пострадают.

## Ограничения
- Форматирование внутри строки (жирный, ссылки) хранится только в блоках; в `.txt` остаётся обычный текст.
- Лимит заметки: 262 144 символа и 1 МиБ. Файлы больше показываются как «не загружен в редактор» и не изменяются.
