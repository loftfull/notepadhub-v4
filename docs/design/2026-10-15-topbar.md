# Верхняя строка: архитектура и структура (2026-10-15)

Запрос владельца: провести мозговой штурм, как оформить верхнюю строку меню, и сделать логичную структуру.

## Что было не так
1. Всё лежало в одной куче: сохранение, метки, отмена, корзина, две заметки, автоформат, картинки, предпросмотр, ИИ, меню, поиск, файлы, тема.
2. Опасная кнопка «В корзину» стояла рядом с «Отменить» и «Предпросмотр».
3. Переход на главную и создание заметки были только в левой библиотеке: при свёрнутой библиотеке их не было.
4. Пункты «Создать/Править изображение» стояли дважды (в строке и в меню «⋯»).
5. Не было границ между группами: глаз не отличал правку от вида.

## Аналоги (что взято)
| Продукт | Что взято |
|---|---|
| Microsoft Word / OneNote | Группы команд с подписями: Правка, Вставка, Вид |
| Notion | Слева место и путь «папка / заметка», справа общие действия и «⋯» |
| Obsidian | Кнопка библиотеки слева, команды в палитре (у нас Ctrl K, «>») |
| Apple Notes | Новая заметка — всегда на виду, поиск — в углу |
| Bear | Статус сохранения тихий, без рамок |
| Google Docs | Название заметки редактируется прямо в строке |
| Evernote | Опасные действия (корзина) убраны в меню |
| Typora | Предпросмотр — переключатель вида, а не отдельная страница |
| VS Code | Разделитель между группами инструментов, поиск и палитра команд на Ctrl K |
| Craft | Один главный акцент (ИИ) выделен цветом, остальное нейтральное |

## Решение: три зоны
```
[≡ Библиотека][Notepad Hub][⌂ Главная][＋ Новая] │ Папка / Название  ✓Сохранено #метка │ Правка | Вставка | Вид | ИИ | 🔍 ⋯ Файл ☾
        зона 1: МЕСТО                                 зона 2: ЗАМЕТКА                          зона 3: ИНСТРУМЕНТЫ
```
1. **Место (слева).** Показать или скрыть библиотеку, главная страница, новая заметка. Работает и при свёрнутой библиотеке.
2. **Заметка (середина).** Путь «папка / название» (клик меняет), состояние сохранения, метка, значки «файл» и «изменён снаружи».
3. **Инструменты (справа)**, группы с тонкими разделителями:
   - **Правка:** отменить, повторить, Автоформат.
   - **Вставка:** изображение (создать, править).
   - **Вид:** две заметки рядом, предпросмотр.
   - **ИИ:** одна заметная кнопка.
   - **Общее:** поиск и команды (Ctrl K), «⋯» действия заметки, «Файл» (открыть, перенос, копии), тема.

## Правила
1. Опасные действия (корзина, удаление навсегда) — только в «⋯», на вкладке и клавишей Delete, всегда с вопросом.
2. Каждое действие в одном месте. Дубли убраны.
3. При ширине меньше 1280 px подписи кнопок скрываются, остаются значки с подсказками.
4. При ширине меньше 900 px строка делится на два ряда: инструменты сверху, заметка снизу.

## Не проверено
Вид на экранах ниже 900 px проверен только по CSS-правилам, не в окне.
