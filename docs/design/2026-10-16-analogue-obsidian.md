# Разбор аналога (Obsidian) и решения по переносу (2026-10-16)

Источник: два снимка окна Obsidian с меню файла и панелью списка заметок, присланные владельцем. Obsidian: заметки как файлы на диске, как и у нас. Ссылка для сравнения: https://obsidian.md.

## Что видно на снимках
1. **Меню файла** сгруппировано линиями: вид (обратные ссылки, просмотр, исходный код), разделение окна, действия с файлом (переименовать, переместить, закладка, объединить, свойство, экспорт в PDF), найти и заменить, копировать путь, история версий, внешние действия (открыть в программе, показать в Проводнике), внизу красным «Удалить файл».
2. **Список заметок** карточками: название, две строки начала текста, время; группы «Сегодня» и «Последние 30 дней» с кнопкой сворачивания; панель: назад, проект, поиск, режим, сортировка, оформление, новая заметка.
3. **Окно:** узкая колонка из 15 значков слева, вкладки с кнопкой списка вкладок, стрелки назад и вперёд и путь «проект / заметка», переключатель чтения, справа панель свойств со счётчиками, внизу «Обратных ссылок, слов, символов».

## Решения
| Решение аналога | Решение | Основание |
|---|---|---|
| Меню файла группами, «Удалить» последним красным | **Перенести** | Меньше случайных нажатий; соответствует правилу «опасное отдельно» (R8) |
| «Найти» и «Заменить» в меню | **Перенести** | Были только на `Ctrl+F` и `Ctrl+H`: не видно в меню |
| «Показать в Проводнике» | **Перенести** | Заметки это файлы на диске: у нас это сильнее, чем у облачных аналогов. Путь берёт хост, страница путь не задаёт |
| Копировать ссылку | **Перенести** в виде `[[название]]` | Наши связи между заметками работают по названию |
| Список с группами по дням и сворачиванием | **Перенести** | При 60 заметках название не различает; группы дают порядок |
| Сортировка списка | **Перенести** (по изменению или по названию) | Раньше порядок был случайным |
| Начало текста под названием | **Перенести как выключатель** (по умолчанию выключен) | Помогает различить одинаковые названия; не удваивает высоту без просьбы владельца (R20: компактное меню) |
| Назад и вперёд по заметкам | **Перенести** (`Alt ←/→`) | Привычно по обозревателю; возвращает к заметке без поиска |
| Оглавление по заголовкам | **Перенести** в панель «Содержание и свойства» | Навигация по длинной заметке; не конкурирует с ИИ «Оглавление» (это текст в заметке) |
| Обратные ссылки в нижней строке | **Перенести**, показывать только при N > 0 | Пустые счётчики владельцу не нужны |
| Колонка из 15 значков, плагины | **Отклонить** | Дублирует разделы, нарушает правило «одно действие в одном месте» |
| Переключатель чтения | **Отклонить** | Владелец удалил «Предпросмотр» как бессмысленный (R16) |
| Разделить окно вправо и вниз, открыть в новом окне | **Отклонить** | Две заметки рядом у нас уже есть с выбором сторон (R9); второе окно потребует переписать оболочку |
| Объединить файл с другим, свойства, экспорт в PDF | **Отложить** | Нет просьбы владельца; PDF потребует печати из WebView2 |
| Кнопка «Новая заметка» в панели списка | **Отклонить** | Владелец удалил её из меню (R20) |
| Имя хранилища и переключатель внизу слева | **Отклонить** | Хранилище одно |

## Что реализовано
`ideas-e2e.mjs` проверяет каждый пункт «Перенести»; «Показать в Проводнике» проверен модульным тестом ядра (`Reveal_note_shows_only_the_notes_own_file…`), а в окне его нажатие не воспроизводилось, чтобы тест не открывал Проводник.

# Дополнение: Notebook Navigator (плагин Obsidian), четыре снимка владельца

## Что видно
1. **Поиск:** поле с переключателем регистра и очисткой, «Найдено: 250», выбор сортировки, результаты по заметкам с числом совпадений и несколькими строками контекста, найденное слово подсвечено.
2. **Дерево папок:** вложенные папки с шевронами, панель: новая заметка, новая папка, сортировка, внешний вид, свернуть и развернуть всё.
3. **Порядок разделов:** окно «Изменить порядок навигации» со стрелками и перетаскиванием («Ярлыки», «Недавние файлы», папки).
4. **Дерево со счётчиками** «заметок в папке • во вложенных», группы «Ярлыки» и «Недавние файлы», **календарь месяца** внизу (клик по дню), внизу слева хранилище со значками справки и настроек.

## Решения
| Решение аналога | Решение | Основание |
|---|---|---|
| Результаты поиска с подсветкой, числом совпадений и несколькими строками контекста, итог «Найдено» | **Перенесено** | Раньше одна строка без подсветки; теперь видно, где именно найдено |
| Календарь по дням | **Перенесено** в виде значка в шапке «Заметки» с окном месяца | Не добавляет раздел в меню (R20); дни с заметками отмечены, клик показывает заметки дня из всех проектов |
| Свернуть и развернуть всё | **Перенесено** для групп по дням | У нас нет дерева, но группы по дням свёртываются |
| Дерево вложенных папок со счётчиками | **Отложено**, нужно решение владельца | Потребует иерархии проектов в формате данных (`projects.json`) и переноса старых данных; сейчас проекты плоские и их три. Предложение: добавить поле «родитель» к проекту, показ деревом с шевронами, счётчик «в проекте • во вложенных» |
| Настройка порядка разделов стрелками | **Отклонено** | Порядок блоков закреплён вашим требованием R20 |
| Ярлыки и «Недавние файлы» как группы дерева | **Уже есть** | Блок «Избранное, Недавние, Архив, Корзина» |
| Имя хранилища и переключатель | **Отклонено** | Хранилище одно |
| Сортировка и регистр в поиске | **Не перенесено** | Ранжирование по релевантности лучше для вашего случая; регистр не нужен: поиск без учёта регистра |


## 2026-10-17: ещё настройки Notebook Navigator и как они лежат в нашем окне

Правило размещения: что меняет вид списка — в «Настройках приложения» (внизу, одно место); что делают чаще раза в день — рядом со списком; действие над проектом — на строке проекта. Дублей нет.

| Идея Notebook Navigator | Решение | Где |
|---|---|---|
| Дерево папок с вложенностью | Сделано (R27) | строки проектов: отступ 14 px на уровень, стрелка слева, «вложенный проект» справа при наведении |
| «Показывать заметки подпапок» | Сделано (R28), по умолчанию включено; число у родителя считает вложенные | Настройки → Вид списка заметок |
| Закреплённые заметки сверху списка | Сделано (R28): первая группа «Закреплённые» | список заметок |
| Плотность списка | Сделано (R28): «Компактный список» | Настройки |
| Перетаскивание папок | Сделано: на проект — вложить, под список — на верхний уровень, в себя нельзя | список проектов |
| Заметка за сегодня, календарь | Уже есть (R26) | шапка «Заметки» |
| Цвета и значки папок | Отложено: нужен выбор из набора и поле в `projects.json`; красиво, но не меняет работу | спросить владельца |
| Дерево меток (метка/подметка) | Отложено: метки у нас плоские, перенос потребует разбора формата меток | спросить владельца |
| Панель «Ярлыки» (закреплённые папки и поиски) | Не нужна: «Избранное» уже закрепляет заметки; закрепление проектов даст второй такой же блок | не переносим |
| Две панели (дерево и список рядом) | Уже так: проекты сверху, заметки ниже, окно узкое | не переносим |
| Колонки свойств в списке | Не нужны: группы по дню и начало текста закрывают задачу | не переносим |

Проверка гармонии: на экране три уровня (проекты → заметки → разделы), все кнопки управления деревом видны только при наведении, строка проекта выше строки заметки на 2 px и не нагружена значками. Перетаскивание не заменяет клавиатуру: вложить проект можно только мышью, это остаётся недоработкой.


## 2026-10-17: аналог QuickNote AI (снимок владельца)

Что в нём есть: широкий поиск с «Ctrl K», кнопка «Улучшить текст», режим «Фокус», слева разделы со счётчиками (Все, Сегодня, Неделя, Избранное, Архив, Корзина), темы с цветными точками, карточки заметок (название, начало, тема, дата, срок хранения), «Хранение: день, неделя, месяц, всегда» с автоматическим уходом заметки, строка «Обновлено …», найденное слово подсвечено в тексте.

| Идея | Решение | Почему |
|---|---|---|
| Режим «Фокус» | Перенесено (F11, «⋯», палитра): скрывает панели, остаётся текст и кнопка выхода | действие над видом; один выход, в одном месте |
| «Все заметки» со счётчиком | Перенесено строкой над проектами | у нас не было просмотра всех заметок сразу |
| Подсветка найденного слова в заметке | Перенесено: из поиска заметка открывается с панелью «Найти», слово подсвечено | связывает поиск с текстом |
| «Обновлено …» | Перенесено в нижнюю строку | служебные данные живут внизу |
| Хранение с автоуходом заметки | Не переносим без решения владельца: автоматическое удаление или архивирование опасно для данных | вопрос владельцу: нужен ли автоархив (не удаление) через N дней |
| Сегодня и Неделя как разделы | Не переносим: календарь и группы по дню уже закрывают | дубль |
| Кнопка «Новая заметка» крупно, «Улучшить текст» в верхней строке | Не переносим | владелец убрал кнопку; ИИ живёт в панели ИИ (R2) |
| Карточки с темой и датой | Не переносим: режим «начало текста» и группы по дню уже дают то же | не усложнять список |
