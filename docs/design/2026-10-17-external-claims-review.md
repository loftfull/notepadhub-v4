## Настоящий дефект, найденный при проверке
CI на GitHub падал на каждом запуске (4 из 4): тест `Referenced_file_paths_on_network_shares_are_never_touched_or_listed` требовал, чтобы вызов занял меньше 2 секунд. Код сетевой путь не трогает (замер: проверка путей 8 мс, сеть не задействована), но первый вызов команды моста при «холодном» запуске занимает 3–6 секунд (на моём компьютере 3 с, на GitHub 4–7 с). Граница сделана 15 секунд: настоящая попытка обратиться к недостижимому адресу висит намного дольше. Остальные проверки CI проходили.

Что осталось верным и стоит делать отдельно: разбиение `App.tsx` на части, лицензия, граф ссылок, ленивая загрузка при тысячах заметок.
