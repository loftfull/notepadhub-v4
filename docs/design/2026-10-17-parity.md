# Сравнение с Блокнотом Windows и топовыми приложениями (2026-10-17)

Цель владельца: «ни в чём не уступать стандартному Блокноту Windows». Статус «проверено» означает: есть автоматический тест в окне программы. «Не проверено» означает: код есть, но проверить в живом окне автоматически нельзя.

## Блокнот Windows → Notepad Hub 4
| Возможность Блокнота | Статус | Где |
|---|---|---|
| Вкладки, открыть файл, восстановление вкладок после запуска | есть, проверено | вкладки, «Открыть файлы…» |
| Сохранение | автоматическое, проверено; запись обратно в файл — «Сохранять в файл» | нижняя строка «Сохранено» |
| «Сохранить как» | теперь есть: «Сохранить как текст (.txt)» (UTF-8 с меткой BOM, строки CRLF); окно сохранения показывает система, не проверено | меню «⋯», палитра |
| Печать (Ctrl+P) | есть: `window.print()` и `print.css` (оставляет на бумаге только лист заметки; взято из внешнего разбора); окно печати не проверено | меню «⋯», палитра |
| Отменить, повторить, вырезать, копировать, вставить, выделить всё | есть | верхняя строка, редактор |
| Найти, заменить, следующий и предыдущий результат | есть (открытие панели проверено) | Ctrl+F, Ctrl+H, Enter и Shift+Enter |
| Перейти к строке (Ctrl+G) | добавлено, проверено; «строка» = блок текста | меню «⋯», палитра |
| Дата и время (F5) | добавлено, проверено | меню «⋯», палитра |
| Перенос по словам | добавлено, проверено | Настройки → Текст заметки |
| Шрифт | добавлено три шрифта: обычный, с засечками, моноширинный; выбор размера — масштаб | Настройки |
| Масштаб Ctrl +/−/0, Ctrl и колесо | есть, проверено | нижняя строка |
| Строка состояния: строка, столбец, число знаков | добавлено «Строка N из M, столбец K», слов и знаков | нижняя строка |
| Тёмная тема | есть | Настройки |
| Проверка орфографии | зависит от WebView2; не проверено | редактор |
| Кодировка и тип перевода строки в строке состояния | нет: данные всегда UTF-8, показывать нечего | — |
| Несколько окон (Ctrl+Shift+N) | нет | можно добавить по решению владельца |

## Что есть у топовых приложений и чего нет у нас
| Возможность | Кто имеет | Решение |
|---|---|---|
| Перетаскивание заметки в проект | Notion, Obsidian, Notebook Navigator, Apple Notes | сделано 2026-10-17 (R34), проверено |
| Выбор нескольких заметок (переместить, в архив, в корзину) | Apple Notes, OneNote, Evernote | сделано 2026-10-17 (R34), проверено; пометка меткой пачкой не сделана |
| Шаблоны заметок | Notion, Evernote | по решению владельца |
| Пароль на заметку | Apple Notes, OneNote | по решению владельца: нужен выбор схемы шифрования |
| Напоминания | OneNote, Evernote | не нужны без уведомлений Windows |
| Облачная синхронизация | почти все | сознательно нет: данные только на компьютере |
| Веб-клиппер | Evernote, OneNote | не нужен |
| Экспорт в PDF | все | печать даёт «Сохранить как PDF» через окно печати Windows |
| Вложенные проекты, календарь, поиск с подсветкой, фокус, сравнение двух заметок, история версий, ссылки [[…]], обратные ссылки, ИИ | часть — у Obsidian, Notion | уже есть |
