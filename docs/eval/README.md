# Проверка моделей ИИ на настоящих текстах: состояние

Запуск: `EVAL_MODE=<local|pollinations|ollama-cloud> EVAL_MODEL=<id> node tests/e2e/ai-eval-e2e.mjs <exe> <профиль.zip> tests/e2e/corpus docs/eval/<имя>.jsonl`, разбор: `python -I tests/e2e/ai-eval-report.py docs/eval tests/e2e/corpus docs/eval/REPORT.md`.

**Результатов качества моделей пока нет.** Прогон 2026-10-16 прерван по решению владельца, его данные удалены как недостоверные:
- на gpt-oss:120b 20 заданий из 30 остановил собственный предел программы «Слишком много облачных запросов за минуту»;
- 5 заданий закончились «AI-провайдер завершил поток без текста», хотя тот же запрос напрямую к Ollama возвращает полный ответ (причина в программе не найдена);
- прогон kimi-k3 оборвался вместе с остановкой.

Что подтверждено: шесть облачных моделей аккаунта Ollama (gpt-oss:120b, kimi-k3, deepseek-v4-pro, glm-5.3, mistral-large-4, gemma4:31b) отвечают напрямую, и программа видит их через сервис «Ollama: облачные модели вашего аккаунта».
