## 1. SPEC — что и зачем (без решений реализации)

**Проблема / результат для пользователя:** (1) нельзя отменить действие при правке текста; (2) предложения AI показывают `##` и теряют форматирование; (3) нет главной страницы, куда можно бросить любой материал и получить автоматическое исследование; (4) в интерфейсе много дублирующих разделов.

**Пользовательские сценарии (Given / When / Then):**
1. Given открыта заметка, When я правлю текст и нажимаю «Отменить» или Ctrl+Z, Then последнее действие отменяется; «Повторить» или Ctrl+Y возвращает его.
2. Given AI вернул предложение с заголовками и списками, When я смотрю его, Then заголовки видны как заголовки, без `##`; When нажимаю «Применить» к абзацу или выделению, Then жирный, курсив и ссылки сохраняются.
3. Given я на главной, When бросаю файлы или вставляю текст, Then для каждого материала создаётся заметка, и AI автоматически готовит анализ (краткое содержание, ключевые пункты, вопросы) в этой заметке отдельным блоком.
4. Given запущен автоанализ, When он идёт долго или не нужен, Then я могу остановить его одной кнопкой.
5. Given я смотрю боковую панель и меню, When ищу действие, Then каждое действие есть в одном месте.

**Критерии приёмки:**
- [ ] AC1 Кнопки «Отменить» и «Повторить» в верхней панели; недоступны, когда нечего отменять; Ctrl+Z / Ctrl+Y работают.
- [ ] AC2 В панели AI ни одна строка предложения не начинается с `#`, `**`, `- ` как символы разметки: показывается отформатированный текст.
- [ ] AC3 «Применить» для абзаца и выделения сохраняет жирный, курсив, ссылки из ответа; применение отменяется одним Ctrl+Z.
- [ ] AC4 Главная страница открывается при запуске без открытых заметок и по кнопке «Главная»; есть зона «бросьте файлы», выбор файлов, поле «вставить текст»; недавние и закреплённые заметки показаны здесь.
- [ ] AC5 Принятый материал становится заметкой; автоанализ запускается сам (по умолчанию локальная модель), результат пишется в заметку блоком «Анализ AI» и не заменяет исходный текст.
- [ ] AC6 Облачная модель при автоанализе запускается только с существующим согласием и подтверждением стоимости; без них автоанализ не стартует и предлагает включить его вручную.
- [ ] AC7 Дубли убраны: нет двух кнопок сворачивания навигации, нет раздела «Библиотека» с нулевыми счётчиками рядом с «Проектами», нет пары «Краткое резюме» / «Анализ заметки».
- [ ] AC8 Существующие проверки не ломаются: `npm test`, `dotnet test`, `host-e2e.mjs`.

**Состояния и границы:** пустой ввод; файл больше лимита редактора (остаётся ссылкой, анализ по началу текста); несколько файлов за раз (до 10); модель недоступна (заметка создаётся, анализ помечается «не выполнен»); повторный сброс того же файла.

**Не входит:** PDF, DOCX, веб-страницы по ссылке (нужны новые пакеты и слово владельца); облачная синхронизация; поиск по интернету.

**Нефункциональное:** доступность WCAG 2.2 AA (кнопки с именами, фокус, клавиатура); приватность: по умолчанию текст не уходит с компьютера; стоимость облачных вызовов только с подтверждением; производительность: интерфейс не блокируется во время анализа.

**Открытые вопросы:** нет. Решено 2026-10-14: PDF/DOCX отложены до слова владельца.

## 2. PLAN — как (решения и затронутые файлы)

- Подход и почему: предложения AI разбираются в блоки (`tryParseMarkdownToBlocks`) и показываются тем же рендером, что предпросмотр; вставка абзаца и выделения идёт через inline-содержимое блоков. Главная — отдельный вид, приём материалов — существующие `openFiles`/`importTextFile`, анализ — существующая операция `analyze`. Альтернатива (новая библиотека разметки) отвергнута: лишняя зависимость.
- План файлов и границ: трогаем `ui/src/App.tsx`, `ui/src/components/AiAssistantPanel.tsx`, `ui/src/layout-v4.css`, новые `ui/src/components/HomeView.tsx` и `ui/src/aiMarkdown.ts`, тесты в `ui/tests`. Хост (`src/`) не трогаем.
- Данные и миграции: формат заметок не меняется, блок анализа — обычные блоки заметки; миграций нет. Откат: копия `ui/src` и `ui/tests` в `C:/Users/Vladimir/Backups/NotepadHub-ui-src-20261014`.
- Зависимости: новых нет.
- Риски и как проверим: API BlockNote для inline-содержимого и истории; проверка юнит-тестами и e2e на реальном хосте с копией профиля; риск ухода текста в облако при автоанализе закрыт существующим согласием и подтверждением стоимости.
- Контрольные точки: после задач 3, 5 и 7 запуск `npm test` и сборки; при провале возврат к копии `ui/src`.
